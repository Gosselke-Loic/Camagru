# Camagru

A fullstack web application that allows users to create and customize images using their webcam or uploaded files. This project is a complete social media MVP, featuring user authentication, real-time image processing, and social interactions.

---

### Key Features
- **Photo Booth:** Capture photos via webcam or upload local images, with a library of transparent stickers to overlay.
- **Image Processing:** Server-side merging of images and stickers into a final composition.
- **User Authentication:** Secure sign-up/sign-in with password hashing and email verification.
- **Social Interaction:** Users can "Like" and "Comment" on shared photos.
- **Responsiveness:** A fully adaptive UI for mobile, tablet, and desktop.
